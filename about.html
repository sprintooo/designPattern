About This Course

A free, open-source resource for software engineers who want to actually understand design patterns — not just memorize them.

What is this?

This is a self-paced course covering 21 of the most important software design patterns, organized into three families: Creational, Structural, and Behavioral. Each lesson explains the problem a pattern solves before showing the solution, so you understand the "why" instead of just the "what."

The patterns with a "Repo ✓" badge are backed by real Java implementations you can read, run, and experiment with directly in the source repository.

Who is it for?

  • Software engineers who write Java (or any OOP language) and want to write better-structured code
  • Developers preparing for system design or technical interviews
  • Anyone who has heard terms like "Factory" or "Observer" but never had them explained clearly
  • Engineers who want to understand the trade-offs of each pattern, not just when to apply it

How to use it

The Roadmap shows a suggested learning order: start with Creational patterns (they're foundational), move to Structural, then tackle Behavioral. Each pattern links to the previous and next, so you can walk through them sequentially.

Use the Mark as Complete button on each lesson to track your progress. Your progress is stored locally in your browser — no account required, nothing is sent anywhere.

Technologies

  • Java — all pattern implementations
  • HTML / CSS / Vanilla JS — site, no framework
  • highlight.js — syntax highlighting for code blocks
  • Inter + JetBrains Mono — typography via Google Fonts
  • GitHub Pages — hosting (free, static, no backend)
